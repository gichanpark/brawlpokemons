# 도트(픽셀) 그림 가이드 — 브롤포켓몬즈 스킨·이펙트·배너

스킨이나 이펙트를 새로 그리기 전에 먼저 읽을 것.
- 1·2절: 게임 안 실제 에셋(dev/assets/icons.js 169개, por.js 168개)을 분석한 값.
- 3·4절: 픽셀아트 튜토리얼(Derek Yu, Lospec, Dragonfly Cave 스프라이팅 가이드, Smogon 아바타 가이드)과 PMD 초상화 규격을 정리한 것.

## 1. 박스 스프라이트 (icons.js / SPR)
- 출처는 pokesprite gen8 박스 아이콘. 게임에는 **원본 도트를 ×4로 키운 것**이 들어 있음 (144개 ×4, 23개 ×3).
  - 그리는 건 항상 **원본 해상도**에서 함. 크기는 평균 27×26, 대부분 20~31픽셀.
  - 다 그린 뒤 NEAREST로 ×4.
  - 원본 추출: `img.resize((w//4,h//4), NEAREST)`. 다시 ×4 했을 때 원래 이미지와 같으면 맞는 배율.
- **한 그림 안에서 픽셀 크기를 섞지 말 것.** 2배로 키운 위에 1칸짜리 장식을 찍으면 바로 티가 남(초안 1차 실패 원인).
- 색 수: 중앙값 11색, 투명은 알파 0/255만 씀(반투명 없음).
- 외곽선
  - **바깥 외곽선은 `#313131`**(바깥 테두리 픽셀의 절반). 그림자 쪽(오른쪽 아래)이나 깊은 틈은 `#000000`·`#212121`.
  - **안쪽 구분선**은 원작에 원래 있던 선만 `#313131`로 둠.
  - 새로 넣는 안쪽 선은 검정이 아니라 **그 부위 색의 가장 어두운 단계**로 칠함. 빨간 갑옷 사이 선이면 진홍 그림자색.
  - 도구: `dev/tools/skins/drafts/pkoutline.py` 의 `fix(im, dark_like, orig, oy)`. 바깥은 #313131로, 새로 생긴 안쪽 선은 주변 색의 어두운 단계로 바꿔 줌. 원본의 원래 안쪽 선은 그대로 둠.
- 빛: 왼쪽을 보면 **왼쪽 위**에서, 오른쪽을 보면(rface) 오른쪽 위에서 옴. 위·앞면은 밝고 아래·뒷면은 어둡게.

## 2. 던전 초상화 (por.js / POR)
- PMDCollab SpriteCollab `portrait/XXXX/Normal.png`, **40×40, 최대 15색**(배경색 포함). 실제 중앙값도 15.
- 배경은 단색 하늘색 계열(`#77c7d7` 근처). 얼굴을 꽉 차게 잘라서 배경 픽셀은 보통 180개 안팎.
- 외곽선은 순검정이 아니라 **포켓몬 색이 살짝 섞인 아주 어두운 색**(예: `#262924`, `#120d34`, `#291831`).
- 정면에 가까운 버스트샷. 눈은 위쪽 1/3~1/2 높이, 머리 장식은 위로 잘려도 됨.
- 스킨 초상화는 원본 초상화에서 출발. 배경은 가장자리에서 flood fill로 골라 보존(`bgmask`, blastoise_pirate.py 참고)하고, 15색 제한을 넘지 말 것.

## 3. 도트 기본기 (튜토리얼 요약)
- **선**: 1픽셀 두께에 대각선으로만 이어지게.
  - 계단 길이를 일정하게 하고, 곡선은 위·아래·옆에서 가장 긴 구간, 가운데로 갈수록 짧게.
  - 곡선 중간에 뾰족한 점이나 들쭉날쭉한 부분(jaggies)을 만들지 말 것. 각진 모서리는 진짜 모서리에만.
- **외곽선 생략**: 물체가 다른 것에 닿는 곳(손에 든 물건, 바닥)은 외곽선을 빼야 떠 보이지 않음. 대비가 충분한 안쪽 경계는 선 없이 색 차이로.
- **명암**
  - 재질마다 3단계(밝음·기본·그림자) + 외곽선. 밝기 순서를 지키고, 두 단계를 한 색으로 합치지 말 것.
  - 밝음·그림자 경계는 면이 빛에서 돌아서는 '적도'에 둠.
  - 하이라이트는 작게, 빛을 정면으로 받는 곳에만.
  - 테두리를 따라 고르게 어둡게 하는 **베개 명암 금지**. 덩어리(cluster)로 형태를 조각하듯.
- **색**
  - 어두운 색은 보라 쪽, 밝은 색은 노랑·빨강 쪽으로 색조를 살짝 돌리면(hue shift) 자연스러움.
  - 색 수는 적게. 16색 넘으면 탁해짐.
- **AA(안티에일리어싱)**: 선이 꺾이는 곳 안쪽에만 손으로 중간색을 찍음. **바깥 테두리에는 AA 금지**(배경이 바뀌면 점으로 보임).
- **띠(banding)**: 같은 두께의 색 띠가 나란히 겹치지 않게. 디더링은 넓은 단색 면이나 거친 질감에만 조금.
- **자주 하는 실수**
  - 색만 바꾸기, 전부 검정 외곽선, 평평한 단색 부위.
  - 좌우 복사·뒤집기를 하고 빛 방향을 안 고친 것.
  - 덧붙인 부위끼리 명암 방향이 안 맞는 것.

## 4. 스킨 그릴 때 순서 (이 게임 규칙)
1. **색만 바꾸는 필터 금지** — 도트를 직접 찍을 것.
2. **장식을 위에 '얹지' 말고 부위를 바꿔 그리기.** 원래 실루엣과 포즈를 유지하면서 머리→투구, 어깨→어깨갑옷, 몸통→갑옷, 날개→칼처럼 원래 부위를 그 테마의 물건으로 바꿈. 모자·관은 머리 모양을 감싸게.
3. 실루엣은 위로만 조금(3~4칸) 넘쳐도 됨. 넘친 부분도 원본 해상도.
4. 재질마다 3단계 팔레트를 먼저 정하고, 빛 방향(왼쪽 위)에 맞춰 칠함.
5. `pkoutline.fix` 로 외곽선을 포켓몬 규칙에 맞춤.
6. **밝은 배경(잔디색 `#c6dea0` 등)에서** 원본과 나란히 ×6~9로 비교. `#313131` 외곽선은 어두운 배경에선 안 보임. 게임 크기(×4)로도 한 번 볼 것.
7. 초상화도 같은 테마로(15색 이하). 게임에 넣을 때는 skins.js 에 `spr`(×4), `por`(40×40).

참고 코드: `dev/tools/skins/drafts/samurai_scizor.py` (부위 바꾸기 + 패치 격자 방식), `dev/tools/skins/blastoise_pirate.py`, `dev/tools/legend_hand/`.
